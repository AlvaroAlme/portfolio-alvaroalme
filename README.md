# Portfolio · Alvaro Almecija Vicente

Sitio web personal donde presento quién soy, mis habilidades y una selección de proyectos, pensado como carta de presentación para procesos de selección como desarrollador web.

## Tecnologías

- HTML5
- CSS3 (diseño responsive con media queries)
- JavaScript (menú hamburguesa y funcionalidad de la interfaz)

## Contenido

- `index.html`: estructura de la página (inicio, sobre mí, proyectos, contacto).
- `style.css`: estilos generales del sitio.
- `mediaqueries.css`: adaptación responsive para móvil y tablet.
- `script.js`: lógica del menú de navegación.
- `assets/`: imágenes y CV en PDF.
